## O que é um Pull Request?

Um Pull Request (PR) é uma proposta de mudança no código. Em vez de alterar diretamente a branch principal, você:

1. Cria uma branch separada com suas mudanças
2. Abre um PR descrevendo o que foi feito
3. O PR é revisado e, se aprovado, mesclado na branch principal
